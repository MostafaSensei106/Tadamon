Future<bool> checkConnection()

Checks if the device has an internet connection.

If the device is not connected to the internet, it shows an error toast message to the user with the message 'لا يوجد اتصال بالانترنت'. This method returns a boolean value indicating whether the device is connected or not. If the device is connected to the internet, the method returns true, otherwise it returns false.

Implementation

Future<bool> checkConnection() async {
  final connectivityResult = await (Connectivity().checkConnectivity());
  if (connectivityResult.contains(ConnectivityResult.none)) {
    return false;
  }
  return true;
}

Scans a barcode from an image selected by the user.

Initiates a feedback vibration and emits a loading state while the operation is in progress. It attempts to scan a barcode from an image using the ImageScanner. If no valid barcode is found, the method returns early with no further action.

Checks network connectivity to determine the source for retrieving product information. If connected to the internet, it fetches the product information from Firestore using the scanned barcode. Otherwise, it retrieves the product information from the local database.

Displays the product information in a bottom sheet and logs the product to the local database if the context is mounted. Emits a success state upon successful completion. If any error occurs during the process, an error toast is shown with the specific error message.

Implementation

Future<void> imageAnalysisScan(final BuildContext context) async {
  HapticFeedback.vibrate();

  ProductModel product;

  try {
    emit(ProductScanLoading());

    final barcode = await ImageScanner().scanBarcodeFromImage(context);

    if (barcode == '-404' || barcode == '-1') {
      return;
    }

    final isConnected = await NetworkController().checkConnection();

    if (isConnected) {
      product = await FireStoreRepository().getProductBySerialNumber(barcode);
    } else {
      product = await ObjectboxRepository().getTadamonProductBySerialNumber(
        barcode,
      );
    }
    if (context.mounted) {
      _showProductInfo(context, product);
      emit(ProductScanSuccess());
    }
  } catch (e) {
    showErrorToast('Error in imageAnalysisScan: $e');
    emit(ProductScanError(e.toString()));
  }
}
